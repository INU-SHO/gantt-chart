# 線表

ブラウザで動く、ダーク基調のシンプルな線表（ガントチャート）アプリです。

**使う → https://INU-SHO.github.io/gantt-chart/**

## できること

- 期間のあるタスクをバーで表示（6色で色分け）
- 主要なイベントを星・三角・逆三角・ひし形のマークで表示
- 今日の位置を線で表示
- 週表示と月表示の切り替え
- 編集のたびにPC上のファイルへ自動保存（Chrome／Edge）

## データの保存先

線表の中身は、使っている人のブラウザとPCの中にだけ保存されます。サーバーには送信されません。

- **ブラウザ内**: 編集するとすぐ保存され、次に開いたときに続きから使えます。
- **PC上のファイル（Chrome／Edge）**: 最初に保存先を1回選ぶと、以降は編集のたびにそのファイルへ自動で上書き保存されます。
- **控え**: 「ファイル」から、いつでも書き出し・読み込みができます。

閲覧履歴の削除でサイトデータを消した場合は、「既存のファイルを開く」で保存先のファイルを選び直すと元に戻ります。

## 対応ブラウザ

| ブラウザ | 表示・編集 | ファイルへの自動保存 |
| --- | --- | --- |
| Chrome／Edge | ○ | ○ |
| Firefox／Safari | ○ | ×（控えの書き出し・読み込みは可） |

## 補足

- 文字の表示に Google Fonts を使っています。ページを開くとフォントの取得のために Google のサーバーへ接続しますが、線表の内容は送信されません。
- 扱える日付は1990年〜2100年、項目は1000個までです。

## 構成

`index.html` 1ファイルだけで動きます。ビルドや外部ライブラリは不要です。
